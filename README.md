# Figures

Проект содержит три фигуры: прямоугольник, круг и квадрат. Все фигуры
наследуются от `Figure`, вычисляют площадь, перемещаются, масштабируются и
поворачиваются на 90 градусов.

## Входные данные

- `Rect(x, y, width, height)` — координаты левого нижнего угла, ширина и высота.
- `Circle(x, y, radius)` — координаты центра и радиус.
- `Square(x, y, side)` — координаты левого нижнего угла и длина стороны.

Ширина, высота, радиус и сторона должны быть положительными. При попытке
создать фигуру с некорректным размером программа завершится с ошибкой.

Метод `move(dx, dy)` принимает смещение по двум осям. `resize(zoom)` принимает
положительный целый коэффициент масштабирования. `rotate(direction, centerX,
centerY)` принимает направление и координаты центра поворота.

## Результат работы методов

- `area()` возвращает площадь фигуры в виде `Float`.
- `move()` изменяет координаты фигуры.
- `resize()` изменяет размеры, сохраняя координаты и пропорции.
- `rotate()` поворачивает фигуру на 90 градусов вокруг заданной точки. После
  поворота прямоугольника его ширина и высота меняются местами.

## Демонстрация

В `Main.kt` создаются три фигуры. Затем они перемещаются на `(1, -1)`,
увеличиваются в два раза и поворачиваются вокруг `(0, 0)` сначала по часовой,
а затем против часовой стрелки. Фигуры помещаются в массив `Array<Figure>`,
который используется для их общего вывода.

Вывод программы:

```text
Circle: x=2, y=0, radius=4, area=50.265484
Square: x=-1, y=-3, side=4, area=16.0

After clockwise rotation around (0, 0):
Rect: x=1, y=-11, width=4, height=8, area=32.0
Circle: x=0, y=-2, radius=4, area=50.265484
Square: x=-3, y=-3, side=4, area=16.0

After counterclockwise rotation around (0, 0):

Circle: x=2, y=0, radius=4, area=50.265484
Square: x=-1, y=-3, side=4, area=16.0
```
